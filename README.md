# Excel Dashboard
Beginner data analysis dashboard built in Excel — data cleaning, pivot tables, and visualizations.

## Overview
An interactive E-commerce order performance dashboard built in Excel, 
analyzing 891 cleaned orders across products, payment methods, order 
status, and referral sources.

## Tools Used
- Microsoft Excel (PivotTables, Slicers, Sparklines, Charts)
- Dataset: Online Store Orders

## Process
1. Data cleaning — removed duplicates and invalid rows (1200 → 891 rows)
2. Analysis — PivotTables for revenue and order breakdowns by category
3. Visualization — pie chart, bar charts, KPI cards with sparklines
4. Interactivity — slicers connected across all charts for live filtering

- Total Revenue: $942,360.55
- Total Orders: 891
- Average Order Value: $1,057.64
- Delivered Rate: 20.1%

## What I Learned
Learned how to clean real-world messy data, build multiple connected 
PivotTables, and design an interactive dashboard using slicers and 
sparklines. Understanding how slicer report connections work was the 
biggest troubleshooting challenge — each slicer must be explicitly 
linked to every PivotTable it should control.
